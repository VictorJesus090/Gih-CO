Gih Oliveira & Co. — Site Institucional

Site de apresentação para o trabalho da Gih Oliveira & Co., com foco em alcançar pessoas que estão organizando um evento (noivas, festas, formaturas) e precisam de cabelo para a ocasião. O site reúne sobre, serviços, depoimentos e contato/agendamento.

Projeto desenvolvido em parceria com a proprietária, como parte do lançamento da nova proposta do negócio.

🔗 Sobre o projeto

Este projeto foi construído com vibe coding (auxílio de IA) para acelerar o desenvolvimento, já que precisávamos publicar logo para a cliente ver e apontar o que quer ajustar. A IA funciona como um apoio criativo no processo, mas o código passa por revisão minha antes de ser considerado pronto.

HTML e CSS: domino a estrutura e a segmentação, e já revisei tudo — semântica, acessibilidade básica (skip link, aria-labels, uso de <symbol>/<use> para os ícones) e organização das seções.
JavaScript: ainda é meu ponto de maior aprendizado. Estou estudando ativamente para entender e validar cada trecho (menu mobile, carrossel de depoimentos, fade-in ao rolar a página) em vez de apenas aceitar o que foi gerado.
Toda saída de IA está sendo tratada como rascunho, não como verdade absoluta — reviso, testo e ajusto antes de publicar.
🛠️ Tecnologias
HTML5 semântico
CSS3 (fontes Google: Jost e Playfair Display)
JavaScript (vanilla) — menu responsivo, carrossel e animações de entrada
